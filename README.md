# Simple C CLI Calculator

A clean, light, and interactive command-line interface (CLI) calculator written in C. Built with standard libraries, featuring robust user input handling and buffer clearing.

## Features

- **Basic Arithmetic Operations**: Supports Addition, Subtraction, Multiplication, and Division.
- **Input Validation**: Safely handles non-numeric inputs using custom stream buffer clearing.
- **Edge-Case Handling**: Includes checks for division-by-zero errors.
- **Formatted Floating-Point Output**: Displays division results accurately rounded to two decimal places.
